# 📝 React Notes App

A simple and responsive Notes App built using **React** and **Tailwind CSS**.

## Features

- Add notes with a title and description.
- View recently added notes.
- Delete notes whenever you want.
- Responsive layout.
- Simple and clean UI.

## Built With

- React
- JavaScript
- Tailwind CSS
- Vite

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
